# Project 1: Standard Row-Major Parallel Matrix Multiplication (Sequential vs OpenMP)

## Overview
This project is a **100% standalone, pure C/OpenMP** implementation of **dense square matrix multiplication ($C = A \times B$)** using two execution models:
1. **Sequential Baseline (C99)**: Single-threaded baseline evaluating algorithmic complexity $\mathcal{O}(N^3)$.
2. **OpenMP Parallel Version (C99 + OpenMP)**: Shared-memory multi-core parallelization using `#pragma omp parallel for schedule(static)` with thread-private accumulation registers to eliminate false sharing.

All benchmarking, timing with `omp_get_wtime()`, statistical computations (Mean, Min, Std-Dev, Speedup, Parallel Efficiency), ASCII table rendering, and CSV/TXT exports are implemented directly in native C with zero external runtime dependencies.

## Build & Execution Instructions

### Option 1: Automated C Benchmark Suite (Recommended)

#### Using Make:
```bash
cd project1
make all
make run
```

#### Manual Compilation with GCC:
```bash
cd project1
gcc -O3 -Wall -fopenmp -static src/benchmark.c -o bin/benchmark -lm
./bin/benchmark
```

* **What it does**:
  1. Runs pre-flight correctness validation ($N=500$, threads=4).
  2. Executes 1 warmup run + 3 measured repetitions across matrix dimensions ($500 \times 500$, $1000 \times 1000$, $2000 \times 2000$) and OpenMP thread counts ($2, 4, 8$).
  3. Measures wall-clock time with `omp_get_wtime()`.
  4. Computes Mean runtime, Min runtime, Standard Deviation, Speedup ($S = T_{seq}/T_{par}$), and Parallel Efficiency ($E = \frac{S}{p} \times 100\%$).
  5. Renders formatted ASCII summary tables to `stdout`.
  6. Exports results to `benchmark/results/project1_results.csv` and `benchmark/results/project1_results.txt`.

---

### Option 2: Standalone Single-Configuration Executables

#### 1. Compile & Run Sequential Program:
```bash
gcc -O3 src/matmul_seq.c -o bin/matmul_seq -lm
./bin/matmul_seq 1000
```
*(Parameter `1000` is the matrix dimension $N \times N$)*

#### 2. Compile & Run OpenMP Parallel Program:
```bash
gcc -O3 -fopenmp src/matmul_omp.c -o bin/matmul_omp -lm
./bin/matmul_omp 1000 4
```
*(Arguments: `<matrix_size>` `<num_threads>`)*

## Performance Metrics & Formulas

### 1. Speedup ($S_p$)
$$S_p = \frac{T_{\text{sequential}}}{T_{\text{parallel}}(p)}$$

### 2. Parallel Efficiency ($E_p$)
$$E_p = \left( \frac{S_p}{p} \right) \times 100\%$$

## Technical Insights
* **False Sharing Mitigation**: Each OpenMP thread computes intermediate dot products in a thread-private CPU register (`double sum = 0.0;`) before writing once to $C[i \cdot N + j]$, preventing threads from invalidating adjacent cache lines in multi-core L1 caches.
* **Static Loop Partitioning**: Rows are mapped statically across threads (`schedule(static)`), providing zero scheduling overhead for uniform $\mathcal{O}(N^3)$ computational workloads.
