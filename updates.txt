# TIMING

Use reliable wall-clock timing.

Prefer Python's:

```python
time.perf_counter()
```

around the subprocess execution.

For example, conceptually:

```python
start = time.perf_counter()

subprocess.run(..., check=True)

elapsed = time.perf_counter() - start
```

Do NOT include compilation time in the measured execution time.

Only measure the matrix multiplication program execution.

---

# REPEATED MEASUREMENTS

For each configuration, run the program multiple times.

Prefer:

```text
3 warm-up runs
5 measured runs
```

or another reasonable methodology if the existing project structure suggests something better.

Report:

* Mean execution time
* Minimum execution time
* Standard deviation if practical

Avoid using a single noisy measurement.

Make the number of repetitions configurable at the top of the script.

For example:

```python
WARMUP_RUNS = 1
MEASURED_RUNS = 3
```

Do not make the benchmark unnecessarily slow on the 2000×2000 case.
